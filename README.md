# AVEC VINCENT — V4 bis

Version indépendante du site AVEC VINCENT, centrée sur Vincent et ses cours particuliers du lycée à la prépa ECG. Le dépôt V4 d’origine n’est pas modifié.

Site statique : ouvrez `index.html` pour la page d’accueil. Les pages comprennent les cours et tarifs, le parcours et la méthode, le crédit d’impôt, la réservation et les informations légales. La page dédiée aux professeurs de la version précédente a été retirée.

## Champs à compléter avant publication commerciale

Les coordonnées et identifiants personnels sont volontairement remplacés par des champs à compléter : identité et adresse professionnelle, SIREN/SIRET, e-mail, téléphone, déclaration SAP et coordonnées de l’hébergeur. Les coordonnées de contact s’affichent dans `reserver.html` et le pied de page ; elles se règlent dans `script.js`.

Le formulaire conserve son endpoint Apps Script existant ; l’adresse destinataire du formulaire est configurée côté Apps Script, pas dans les pages publiques du dépôt.
